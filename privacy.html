CXO News プライバシーポリシー

中満悠人（以下「運営者」）は、iPhoneアプリ「CXO News」（以下「本アプリ」）における利用者の情報の取り扱いを、次のとおり定めます。

1. 取得する情報

本アプリは、次の情報を取得します。氏名、メールアドレス、電話番号、位置情報、連絡先、写真は取得しません。

情報内容取得のしかた
利用者ID本アプリが自動で発行する識別子（匿名）「はじめる」を押したとき
登録した会社利用者が登録した会社と、その会社との「仲の良さ」利用者が入力したとき
利用者についての情報（任意）生まれ年、会社名、業種、業態、会社の設立年利用者が入力したとき
「刺さった」の記録利用者が「刺さった」を押した記事利用者が押したとき
通知の設定通知の頻度利用者が選んだとき
ログイン状態本アプリを開いたままにするための情報利用者の端末の中にだけ保存します

2. 利用の目的

取得した情報は、次の目的にだけ使います。

  1. 登録した会社のニュースを集め、利用者に表示するため
  2. ニュースの重要度を利用者ごとに計算するため（仲の良さ、生まれ年など）
  3. ニュースの選び方を改善するため（「刺さった」の記録）
  4. 本アプリの不具合の調査と改善のため

広告の表示、利用者の行動の追跡（トラッキング）、第三者への販売には使いません。

3. 他の利用者への公開

「登録した会社」「仲の良さ」「利用者についての情報」「刺さった」の記録は、その利用者本人だけが見られます。他の利用者には表示しません。

会社と、その会社のニュース（公開情報をもとにしたもの）は、その会社を登録した利用者全員に共通で表示します。

4. 外部サービスへの提供

本アプリは、次の外部サービスを使っています。これらのサービスに、目的の達成に必要な範囲で情報を送ります。

サービス提供者送る情報と目的
SupabaseSupabase, Inc.1章の情報を保存するため（データベース・認証）
Claude APIAnthropic, PBC登録された会社の名前・公開情報をもとに、ニュースを探すため
Gemini APIGoogle LLC公開されたニュース記事を要約・分類するため
gBizINFO経済産業省会社を法人番号で探すため（社名だけを送ります）
TestFlightApple Inc.テスト版の配布と、クラッシュ情報の収集のため（Appleのプライバシーポリシーに従います）

Claude API と Gemini API に送るのは、会社名と、インターネット上に公開されている記事です。利用者の生まれ年などの情報は送りません。

これらのサービスは日本国外にサーバーを置いていることがあり、情報は国外で保存・処理されることがあります。

法令にもとづく場合を除き、上の目的以外で第三者に情報を提供しません。

5. 保存期間と削除

  • 情報は、本アプリの提供に必要な間、保存します。
  • 本アプリは匿名で使うため、ログアウトしたり本アプリを削除したりすると、同じ利用者IDに戻ることはできません。
  • 情報の削除を希望する場合は、設定画面に表示される「ユーザーID」を添えて、7章の連絡先までご連絡ください。確認のうえ、その利用者IDに紐づく情報を削除します。

6. 安全管理

  • 通信は暗号化（HTTPS）しています。
  • データベースでは、利用者本人の情報を本人だけが読み書きできるように制限しています。
  • 外部サービスのAPIキーなどの秘密の情報は、本アプリには含めず、サーバー側だけで管理しています。
